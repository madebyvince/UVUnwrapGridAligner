## Description
**UVUnwrapGridAligner** is a Blender addon that helps you cleanly organize UVs into a straight, evenly spaced grid.
It takes selected UV rows (typically top and bottom of strips), aligns them to Y = 1.0 and Y = 0.0, and distributes their X positions evenly from 0.0 to 1.0.
Perfect for making UV strips clean, uniform, and normalized — ideal for lightmaps, atlases, or procedural workflows.

---

## Installation

1. Download the addon zip archive (`UVUnwrapGridAligner.zip`).
2. In Blender, go to `Edit > Preferences > Add-ons`
3. Click `Install...` and select the `.zip` file
4. Enable the addon named **UVUnwrapGridAligner**
5. Find it under `UV > Unwrap Grid Tools > Distribute and Align Unwrapped UV Grid`

---

## Usage

- In Edit mode, select only the faces you want to realign
- Ensure the UVs are laid out in a row-like structure
- Run the tool from the UV menu
